# Microsoft 365 User Onboarding Lab

## Overview

This lab demonstrates the process of onboarding a new employee in a Microsoft 365 environment.

## Scenario

A new employee joins the company and requires:

- A Microsoft 365 account
- An Exchange Online mailbox
- Group membership
- Multi-Factor Authentication (MFA)

## Technologies Used

- Microsoft Entra ID
- Microsoft 365 Admin Center
- Exchange Online
- Microsoft Authenticator
